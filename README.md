# znznzna/homebrew-tap

```sh
brew install znznzna/tap/imgscrub
```

| Formula | 説明 |
|---|---|
| [imgscrub](https://github.com/znznzna/imgscrub) | JPEG から C2PA と追跡用メタデータを取り除く（画素は触らない） |

## Tap Trust について

Homebrew はサードパーティ tap の初回インストール時に信頼の確認を求める。
表示される内容を読んで承認する（`brew tap znznzna/tap` を先に実行しておくのも可）。
